# One Piece API

This is an Express.js API with a front-end that shows the WANTED posters of the Straw Hat members, stored in a PostgreSQL database.

## Purpose
This project was created to demonstrate my deployment skills using Docker and Docker Compose. It has no major practical utility (at least not yet!).

## Deployment
To get this project working, make sure you have Docker installed. Then, open your terminal in the project directory and run:

```bash
docker compose up --build
